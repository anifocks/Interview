This is a very suitable application for React + Node.js + SQL Server, and I would recommend building it as two initial microservices rather than making the system unnecessarily complicated.

One important point first: the SQL Server password you posted is a real credential-looking value. Do not commit it to GitHub or put it in React code. Keep it only in .env on the server, and rotate it if it is an active production credential.

18. Node.js Database Connection

Since your database is SQL Server, I recommend the Node package:

mssql

Your database configuration can be:

const sql = require("mssql");

const config = {
    user: process.env.DB_USER,
    password: process.env.DB_PASSWORD,
    server: process.env.DB_HOST,
    database: process.env.DB_DATABASE,
    options: {
        encrypt: false,
        trustServerCertificate: true,
        instanceName: process.env.DB_INSTANCE_NAME
    },
    pool: {
        max: 10,
        min: 0,
        idleTimeoutMillis: 30000
    }
};

const poolPromise = new sql.ConnectionPool(config)
    .connect()
    .then(pool => {
        console.log("Connected to SQL Server");
        return pool;
    })
    .catch(err => {
        console.error("Database connection failed:", err);
        throw err;
    });

module.exports = {
    sql,
    poolPromise
};

If MEPZ_TEST_4_INST is a named SQL Server instance, we should verify the SQL Server Browser/network configuration when you run it.

19. Example Controller

For example:

controllers/questionController.js
const { sql, poolPromise } = require("../config/db");

const getQuestions = async (req, res) => {
    try {
        const pool = await poolPromise;

        const result = await pool.request().query(`
            SELECT
                QuestionId,
                QuestionCode,
                QuestionText,
                QuestionType,
                Category,
                Difficulty,
                IsCommon,
                IsActive
            FROM Questions
            WHERE IsActive = 1
            ORDER BY CreatedAt DESC
        `);

        res.json({
            success: true,
            data: result.recordset
        });

    } catch (error) {
        console.error(error);

        res.status(500).json({
            success: false,
            message: "Failed to get questions"
        });
    }
};

module.exports = {
    getQuestions
};
